# Кино-Редиректор 

Микро-расширение для браузера Vivaldi (и других Chromium-браузеров), которое в один клик перенаправляет с текущей страницы Кинопоиска на аналогичную страницу Кинокино.

## Как установить локально:
1. Скачайте этот репозиторий в виде ZIP-архива и распакуйте.
2. Откройте Vivaldi и перейдите по адресу `vivaldi://extensions/`.
3. Включите **Режим разработчика** в правом верхнем углу.
4. Нажмите **Загрузить распакованное расширение** и выберите папку с проектом.
